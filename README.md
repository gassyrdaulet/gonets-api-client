<h1 align="center">GoNets 1.0.1</h1>

Бесплатный и лёгкий аналог Postman: не требует регистрации и входа через интернет, работает быстро и без лагов.

Клиент для HTTP-запросов: коллекции с папками, окружения с переменными, автоматическая авторизация
(вход, обновление токена), JSON и XML/SOAP, транспортная подпись ШЭП (SOAP, ГОСТ).

## Что нужно

- **JDK 17 или новее** (проверено на 24). Для портативной сборки нужен `jpackage` из JDK.
- **Maven 3.9**.
- **Библиотеки Калкан** (НУЦ РК).

## Запуск

Из исходников:

```powershell
mvn javafx:run
```

Или собрать и запустить jar (рядом с ним папка `lib/` со всеми зависимостями):

```powershell
mvn package
```

```powershell
java -jar target/app/gonets.jar
```

## Установщик для Windows

```powershell
mvn -Pinstaller package
```

Получится `target/installer/GoNets-<версия>.exe` (около 47 МБ). Он ставит приложение для текущего пользователя в
`%LOCALAPPDATA%\Programs\GoNets` без прав администратора, предлагает выбрать папку и ярлыки (меню «Пуск», рабочий стол),
удаляется через «Параметры → Приложения». Новая версия ставится поверх старой. Данные (`%APPDATA%\Gonets\data.json`)
при удалении и обновлении не трогаются.

Для сборки нужен WiX Toolset 5 (один раз):

```powershell
dotnet tool install --global wix --version 5.0.2
```

```powershell
wix extension add -g WixToolset.Util.wixext/5.0.2 WixToolset.UI.wixext/5.0.2
```

## Портативная сборка для Windows

```powershell
mvn -Pdist package
```

Получится `target/dist/GoNets/` с `GoNets.exe` (около 63 МБ) и архив `target/dist/GoNets-<версия>-portable.zip` (около 46 МБ).
Установка не требуется: распакуйте и запустите `GoNets.exe`. Обе сборки сразу: `mvn -Pdist,installer package`.

## Сборка для macOS и Linux

```bash
mvn -Pdist-mac package     # на Mac: target/dist/GoNets.app и GoNets-<версия>-mac.zip
mvn -Pdist-linux package   # на Linux: target/dist/GoNets/ и GoNets-<версия>-linux.tar.gz
```

- На macOS окно с системной рамкой, в подсказках ⌘ вместо Ctrl. Шрифты подбираются из установленных (Menlo, Helvetica Neue и т. п.).
- Иконка для Mac `build/icon.icns` собирается из `build/icon.png`: `java scripts/MakeIcns.java`. Для Linux берётся `build/icon.png`.
- Данные: `~/Library/Application Support/Gonets/data.json` на Mac, `~/.config/Gonets/data.json` на Linux.
- Проверено только сборкой и запуском на Windows: сборки для Mac и Linux в этом репозитории не прогонялись.

## Переменные и генерируемые значения

`{{имя}}` подставляет переменную окружения в URL, заголовки, тело и авторизацию. Кроме того, есть генераторы:

| Генератор | Значение |
|---|---|
| `{{$uuid}}` | случайный UUID |
| `{{$now}}` | местное время с поясом: `2026-11-20T17:00:00.000+05:00` |
| `{{$utc}}` | время UTC: `2026-11-20T12:00:00.000Z` |
| `{{$date}}`, `{{$time}}` | `2026-11-20`, `17:00:00` |
| `{{$timestamp}}`, `{{$timestampMs}}` | Unix-время в секундах и миллисекундах |
| `{{$randomInt}}`, `{{$randomInt:1:9}}` | случайное число (по умолчанию от 0 до 1000) |
| `{{$now:dd.MM.yyyy HH:mm}}` | свой формат даты (так же `$utc`, `$date`, `$time`) |

Прямо в запросе каждое вхождение генератора даёт новое значение. Если генератор записан в значении переменной окружения
(например, `message_id` = `{{$uuid}}`), переменная вычисляется один раз на отправку: во всех местах запроса будет одно и то же
значение, а при следующей отправке — новое. Добавить такую переменную можно кнопкой «+ Генератор» в окне «Окружения».

## Транспортная подпись ШЭП (SOAP, ГОСТ, WS-Security)

Подписывает SOAP Body: ГОСТ 34.10-2015 и 34.11-2015 (512 бит), Exclusive C14N,
сертификат в `KeyInfo/SecurityTokenReference`. Код подписи — `src/main/java/kz/gonets/Signer.java`.

1. **В окружении** (раздел «Транспортная подпись ШЭП»): путь к файлу ключа `.p12` и пароль. Ключ берётся последний в файле. Кнопка
   «Проверить ключ» показывает владельца и срок действия сертификата.
2. **В запросе**: тип тела «XML» или «SOAP» (вкладка «Тело») и галочка «Транспортная подпись ШЭП» на вкладке «Опции». Кнопка «Показать подписанный» открывает
   то, что уйдёт на сервер.

Подпись ставится последней, после подстановки переменных и токена, и тут же проверяется заново по готовому XML.
Файл ключа читается с диска и никуда не копируется, пароль хранится в `data.json` вместе с остальными паролями.

## Защита мастер-паролем

«Настройки → Защита данных → Включить защиту паролем» шифрует весь файл (AES-256-GCM, ключ из пароля через PBKDF2-HMAC-SHA256,
210 000 итераций). Пароль спрашивается при каждом запуске, без него файл не прочитать; забытый пароль восстановить нельзя.
Защита одинаково работает на всех системах, зашифрованный файл можно переносить между компьютерами. Сменить пароль или снять
защиту можно там же (нужен текущий пароль). По умолчанию защита выключена и файл хранится открытым текстом.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Enter | Отправить запрос |
| Ctrl+S | Сохранить запрос |
| Ctrl+F | Поиск в теле запроса и в ответе (Enter / Shift+Enter, F3 — следующее / предыдущее) |
| Ctrl+K | Поиск по запросам в списке |
| Ctrl+= / Ctrl+- / Ctrl+0 | Крупнее / мельче / обычный размер шрифта |
| Ctrl+, | Настройки |
| Alt+Z | Перенос длинных строк вкл / выкл |

В теле запроса — как в VS Code:

| Клавиши | Действие |
|---|---|
| Ctrl+X / Ctrl+C без выделения | Вырезать / скопировать всю строку; Ctrl+V такой строки вставит её над текущей |
| Ctrl+Shift+K | Удалить строку |
| Alt+↑ / Alt+↓ | Переместить строку (или выделенные строки) вверх / вниз |
| Shift+Alt+↑ / Shift+Alt+↓ | Продублировать строку вверх / вниз |
| Tab / Shift+Tab | Отступ / убрать отступ (для нескольких выделенных строк — у всех) |
| Ctrl+] / Ctrl+[ | Отступ / убрать отступ у строки |
| Enter | Новая строка с тем же отступом; после `{`, `[` или открывающего тега — глубже |
| Home | К первому символу строки, повторно — к началу строки |
| Ctrl+L | Выделить строку (повторно — добавить следующую) |
| Ctrl+D | Выделить слово, повторно — следующее такое же |
| Ctrl+/ | Закомментировать / раскомментировать строки (XML и SOAP) |
| Shift+Alt+F | Форматировать |
| Ctrl+Z / Ctrl+Y | Отменить / повторить |

В ответе работают Ctrl+C без выделения, Ctrl+L, Ctrl+D и Home.

## Устройство кода

| Файл | Что делает |
|---|---|
| `Launcher`, `App` | Запуск, одна копия приложения |
| `Model`, `Store`, `Json` | Данные и `data.json` |
| `Http`, `Tokens` | Отправка запросов, автоматическая авторизация и повтор после 401 |
| `Signer` | Транспортная подпись (Калкан) |
| `Logic`, `Pretty`, `Highlight`, `Gen` | Переменные и генераторы, сборка запроса, импорт cURL, отчёт «Отладки», форматирование и подсветка |
| `CodeExport` | Экспорт запроса в код (cURL, PowerShell, fetch, Python, Java, HTTP) |
| `ui/*` | Окна JavaFX: главное окно, окружения, поиск, редактор кода |
